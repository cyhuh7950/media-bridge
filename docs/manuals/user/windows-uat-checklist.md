# Windows 인수 체크리스트

## 설치 전

- [ ] 기존 Media Bridge가 실행 중이지 않다.
- [ ] 사용할 MSI 파일명과 버전을 기록했다.
- [ ] 기존 설정을 보존할지 결정했다.

## 설치·최초 설정

- [ ] MSI 설치가 완료됐다.
- [ ] `http://127.0.0.1:8765/`가 열린다.
- [ ] OpenCodex·Solar endpoint와 정확한 model ID를 저장했다.
- [ ] credential 원문을 입력하지 않았다.
- [ ] `http://127.0.0.1:8766/status`가 응답한다.

## 핵심 사용

- [ ] text-only 코딩 요청이 응답한다.
- [ ] 코드 오류 화면 캡처 요청이 설명 텍스트로 처리된다.
- [ ] 인식이 부족한 캡처는 재캡처 안내로 끝난다.
- [ ] 실패 뒤 다음 text-only 요청이 정상 처리된다.

## 복구·제거

- [ ] 앱 재시작 후 설정이 유지된다.
- [ ] 업데이트 후 설정이 유지된다.
- [ ] 이전 버전 되돌리기 후 앱이 시작된다.
- [ ] 제거 후 앱과 loopback listener가 사라진다.
