# 관리자 인증앱·복구 이메일 2단계 인증 설계

## 목표

 배포형 Media Bridge의 관리자는 고정된 `admin/admin` 기본 계정으로 로그인하고, 인증 앱(TOTP) 또는 복구 이메일을 이용한 2단계 인증으로 관리자 화면에 접근한다.

## 확정 요구사항

- 기본 관리자 계정은 `admin/admin`으로 항상 존재한다.
- 기본 관리자 계정은 삭제할 수 없다.
- 비밀번호 변경 기능은 제공하지 않는다.
- 최초 접속은 인증 앱 등록과 TOTP 확인을 완료해야 한다.
- 일반 로그인은 아이디·비밀번호 검증 뒤 TOTP 코드를 요구한다.
- 인증 앱을 사용할 수 없을 때 복구 이메일로 일회용 복구 코드를 발급한다.
- SMTP 설정값은 시스템 내부 설정에서 읽고, 소스·로그·화면에 비밀값을 노출하지 않는다.
- 복구 코드와 TOTP 검증은 만료·일회성·시도 제한을 적용한다.
- 기존 bootstrap token으로 사용자명·비밀번호를 생성하는 최초 관리자 흐름은 기본 계정 정책과 충돌하므로 제거하거나 비활성화한다.

## 적용 범위

이 변경은 배포형 Control Plane과 그 Web 관리 화면에만 적용한다. 설치형 Media Bridge의 런타임·CLI·설치 문서·설치 테스트는 수정하지 않는다.

## 구성

### 백엔드

배포형 `media_bridge_control`과 배포형 `web`에 기본 관리자 보장, TOTP secret 등록/확인, 2단계 로그인 상태, 복구 이메일 코드 발급/소비를 분리한다. 데이터베이스에는 사용자별 TOTP secret과 등록 상태, 복구 코드의 해시·만료·사용 시각을 저장한다. 평문 비밀번호·TOTP secret·복구 코드는 저장하거나 로그에 남기지 않는다.

로그인은 다음 상태를 거친다.

1. `admin/admin` 자격 증명 검증
2. TOTP 미등록이면 등록 secret/URI를 반환하고 등록 확인을 요구
3. TOTP 등록 상태이면 TOTP 코드 검증
4. TOTP를 사용할 수 없으면 복구 이메일 요청 후 일회용 코드 검증
5. 성공 시 기존 CSRF 보호 세션 발급

기본 admin의 삭제·비활성화·역할 변경·비밀번호 변경 API는 거부한다.

### 프론트엔드

로그인 화면은 자격 증명, 인증 앱 코드, 복구 이메일 코드 흐름을 명확히 구분한다. 최초 등록 화면에는 QR/otpauth URI와 6자리 코드 입력을 제공하고, 복구 흐름에는 이메일 발급과 코드 입력만 노출한다. bootstrap token 입력 화면은 기본 관리자 정책에서는 사용하지 않는다.

### SMTP

SMTP 호스트·포트·보내는 주소·TLS·인증 참조는 서버 설정에서 읽는다. 실제 비밀값은 환경변수 또는 운영 Secret 저장소에서만 주입한다. 설정이 없으면 복구 이메일 기능은 안전한 오류를 반환하고 TOTP 로그인은 계속 사용할 수 있어야 한다.

## 오류와 보안

- 잘못된 자격 증명·TOTP·복구 코드는 동일한 일반 오류로 응답한다.
- 로그인·TOTP·복구 코드 요청에는 기존 rate limit 정책을 확장 적용한다.
- 복구 코드는 한 번 사용하면 즉시 폐기한다.
- 모든 인증 실패와 복구 요청은 감사 이벤트로 기록하되 비밀값은 기록하지 않는다.
- 세션 발급 전에는 관리자 API 접근을 허용하지 않는다.

## 검증 범위

- 인증 서비스 단위 테스트: 기본 admin 보장, TOTP 등록/검증, 복구 코드 일회성·만료·rate limit, 기본 admin 보호
- API 테스트: 로그인 단계 전환, 복구 이메일 발급/검증, SMTP 미설정 오류, 세션/CSRF
- 웹 테스트: 로그인·등록·복구 화면 전환과 오류 표시
- 전체 Python 및 웹 lint/typecheck/build/test

## 설치형 제외

- 설치형 Media Bridge의 인증·CLI·설치 흐름은 변경하지 않는다.
- 설치형 전용 파일과 테스트는 이번 branch에서 수정하지 않는다.

## 범위 밖

- 일반 사용자 계정 체계 확장
- 비밀번호 변경·비밀번호 정책 UI
- 외부 이메일 서비스 연동 자체의 운영 배포
- 기존 Provider·Model·Media Bridge 라우팅 동작 변경
